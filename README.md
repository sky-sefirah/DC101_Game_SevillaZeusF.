Project Instructions: Individual Work

Course: DC 101 – Web Development
Level: 2nd Year

Project Title: Mini Arcade – Build Your Own Browser Game

Mode: Individual Work
Deadline: Dec 12, 2025

Objectives:
Develop a browser-based game using HTML, CSS, and JavaScript, and publish it on GitHub. This project reinforces front-end development skills and introduces students to version control and public repositories.

Game Title: Rock Paper Scissor Game

Description:
a single player rock paper scissor browser game web development DC101 project using html for structure, css for styling and responsiveness and javascript for interactivity and logic.

Instructions:
1.To start playing the game by randomly selecting any of the three choices (rock, paper,scissor)

2.Simultaneously the comp will also randomly select from the choices.

3.There are three possible results in the game that you will see depending on the combination of user and comp choice, first if you win the image borders and result texts above the images that you picked will temporarily glow  green, red if you lose and grey if its a draw, you will also see the result paragraph promp above the images changes.

4.Scores will be recorded at the scoreboard until you reset or refresh the webpage
